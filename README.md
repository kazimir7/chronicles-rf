# 🦅 Хроники России (862 — 2026)

Интерактивный цифровой музей и историко-документальный портал, объединяющий узловые вехи тысячелетнего пути Российского государства и глубокую летопись новейшей истории Российской Федерации (1991 — 2026).

Сайт доступен на: [kirusha.duckdns.org](https://kirusha.duckdns.org)  
Репозиторий проекта: [github.com/kazimir7/chronicles-rf](https://github.com/kazimir7/chronicles-rf)

---

## 🏛️ Ключевые возможности портала

1. **🏛️ Музейная дизайн-система «Dark Sovereign» & «Imperial Light»:**
   - Величественная типографика (`Cinzel`, `Playfair Display`), приглушенные золотые акценты, благородный темный фон и высококонтрастный светлый режим.
2. **⏳ Интерактивная лента веков (Ribbon Timeline):**
   - Быстрый переход по ключевым вехам: 862 (Истоки) ⟶ 988 (Крещение) ⟶ 1242 (Ледовое побоище) ⟶ 1380 (Куликово поле) ⟶ 1480 (Стояние на Угре) ⟶ 1612 (Ополчение) ⟶ 1721 (Империя) ⟶ 1812 (Бородино) ⟶ 1945 (Великая Победа) ⟶ 1961 (Космос) ⟶ 1993 (Конституция) ⟶ 2014 (Крым) ⟶ 2026 (Многополярный мир).
3. **📜 Интерактивная Хронология (6 эпох + тематические фильтры):**
   - Удобное переключение между всеми эпохами государства.
   - Фильтрация по темам: Власть, Военная безопасность, Территории, Экономика, Внешняя политика.
4. **📖 Полноразмерное исследовательское модальное окно (Research Modal):**
   - Полноценная точка входа в каждое историческое событие: контекст, ход событий, ключевые личности, историческое значение, связанные документы и навигация «Назад / Вперед».
5. **🎲 Случайное историческое событие:**
   - Интерактивное открытие одного из ключевых событий с глубоким разбором в один клик.
6. **⭐ Мой исторический архив (Закладки):**
   - Возможность сохранять любые события и документы в избранное через локальное хранилище браузера (`localStorage`) с выдвижной боковой панелью.
7. **🗺️ Интерактивная историческая карта:**
   - 18 ключевых исторических узлов с фильтрацией по эпохам, описанием и переходом к подробному изучению.
8. **👑 Исторические личности:**
   - Творцы истории: князь Владимир, Александр Невский, Иван III, Минин и Пожарский, Петр Великий, Екатерина Великая, Георгий Жуков, Юрий Гагарин.
9. **⚖️ Архив первоисточников и государственных актов:**
   - Выдержки из «Русской Правды», Судебника 1497 г., Манифеста о Крыме 1783 г., Акта о капитуляции 1945 г., Конституции РФ 1993 г., Мюнхенской речи 2007 г., ФКЗ о Крыме 2014 г., Постановления СФ № 35-СФ и ФКЗ о 4 новых субъектах 2022 г. с прямыми ссылками на государственные архивы.
10. **🧠 Исторический квиз с выбором тем:**
    - Проверка эрудиции по отдельным эпохам или общему тесту с подробными объяснениями и присвоением звания.
11. **🔍 Живой полнотекстовый поиск:**
    - Поиск в реальном времени с подсветкой совпадений и быстрыми подсказками.

## 🚀 Развертывание на VPS (Caddy)

На сервере VPS под управлением Caddy достаточно перейти в папку сайта и выполнить:

```bash
cd /srv/tproxy-site
git pull
```

Сайт обновляется моментально без необходимости перезапуска сервисов.
